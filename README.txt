PROJECT TITLE: VaultFinance v1.0
AUTHOR: Florian Ajeti
LANGUAGE: Python 3.12
LIBRARIES: Tkinter (Built-in)

DESCRIPTION:
A secure personal finance tracker with a Graphical User Interface. 
This application allows users to manage their daily income and expenses 
behind a PIN-protected gateway.

KEY FEATURES:
- PIN Authentication: Prevents unauthorized access to financial data.
- Real-time Balance: Updates instantly as transactions are added.
- Dynamic History: Visual list showing income (green) and expenses (red).
- Forecasting: Predictive algorithm to calculate time needed to save for a car.
- Modern UI: Decorated with a custom color palette and card-based layout.

HOW TO RUN:
1. Install Python 3.12
2. Open finance_gui.py in IDLE or any IDE.
3. Run the script (F5).
4. Use Default PIN: 1234
